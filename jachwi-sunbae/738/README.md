동네 찾기에서 `서울시청`을 검색하고 첫 결과인 서울특별시 중구 세종대로 110 서울특별시청을 선택했습니다. 통근 40분 이내, 환승 1회 이하, 월세 전체로 검색한 뒤 결과 지도에서 같은 위치의 소공동(11020520)을 누릅니다.

GIF는 출퇴근 장소 설정과 검색을 마친 결과 지도부터 시작합니다. 전에는 가로로 넓은 `현재 매물 확인하기` 카드와 시트 아래 여백이 보입니다. 후에는 소요시간과 월세 시세 글 오른쪽에 정사각형 다방 타일이 표시되며, 시트가 내용에 맞춰 낮아집니다. 소공동의 소요시간은 2분이며 월세 시세는 거래가 적어 제공되지 않는 상태였습니다.

파일 크기는 완성 GIF의 실제 바이트 수이며, 길이는 GIF 프레임 지연 시간의 합입니다. 성능 측정값은 아닙니다.
