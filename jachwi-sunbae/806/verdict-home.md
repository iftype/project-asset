# 전후 판정

- 화면: `/` (desktop)
- 사용자가 기다리는 순간: 목록의 첫 매물 카드(사진 자리까지 보인 카드)
- 문턱: 흩어짐의 1배, 0.00초 중 큰 값. 차이가 문턱 이하면 같음이다.
- 조건: 회선 fast4g, CPU 4배, 빈 캐시 첫 방문, 전후를 번갈아 각 5회(세지 않는 데우기 1회 뒤), 실제 네이버 지도 SDK와 타일
- 흩어짐 상한: 0.25초. 넘으면 판정 불가(흔들림 큼)이다.
- 전: http://localhost:4301, 후: http://localhost:4302

## 판정: 좋아짐

사용자 기준 순간이 판정을 정한다. LCP는 참고만 한다. 콘솔 오류나 실패한 요청이 후에서 늘면 순간 값과 상관없이 나빠짐이다.

| 지표 | 전 중앙값 | 후 중앙값 | 차이 | 흩어짐 | 문턱 | 판정 |
| --- | --- | --- | --- | --- | --- | --- |
| 사용자 순간 | 2.60초 | 2.53초 | -0.07초 | 0.05초 | 0.05초 | 좋아짐 |
| LCP(보조) | 3.57초 | 3.50초 | -0.07초 | 0.06초 | 0.06초 | 좋아짐 |

- 사용자 순간 회차별(초): 전 2.60, 2.60, 2.59, 2.64, 2.60, 후 2.56, 2.55, 2.52, 2.53, 2.52
- 콘솔 오류 수(회차별): 전 0, 0, 0, 0, 0, 후 0, 0, 0, 0, 0
- 실패한 요청 수(회차별, 4xx와 5xx 포함): 전 0, 0, 0, 0, 0, 후 0, 0, 0, 0, 0
