내 기록 지도 첫 화면에서 내 기록 탭을 다시 누르고 리스트를 확인한 뒤 지도로 돌아와 마이 탭을 엽니다.

전에는 내 기록 탭을 다시 눌러도 보기가 바뀌지 않아 기존 리스트/지도 스위치를 사용합니다. 후에는 내 기록 탭 재선택만으로 지도와 리스트를 오갑니다. 전에는 리스트 위에 없던 `최근 기록한 방` 줄이 후에는 표시됩니다.

하단 탭은 전 6개와 112px, 후 3개와 60px입니다. 높이는 Playwright의 하단 탭 nav 요소 bounding box에서 확인했습니다. 후에는 오른쪽 위 마이 아이콘이 사라지고 마이 화면에 체크리스트, 방 비교, 저렴한 한 끼, 사용방법 바로가기가 표시됩니다.

파일 크기는 완성 GIF의 실제 바이트 수이며, 길이는 GIF 프레임 지연 시간의 합입니다. 성능 측정값은 아닙니다.
